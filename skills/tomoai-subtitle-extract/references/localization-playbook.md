# 中文本地化对照手册

用法：Step 3 改写时，遇到拿不准的表达来这里查。
原则只有一条 —— **查不到就直接按"中国人在这个场景会怎么开口"重写，不要贴近英文词面。**

---

## 1. 填充词与口头禅：整句跳过

英文口语靠填充词撑节奏，中文靠短句和语气词。填充词对中文观众零信息量，一律删。

| 英文 | 别翻成 | 处理 |
|---|---|---|
| you know | 你知道的 | 删 |
| I mean | 我的意思是 | 删（除非真在修正前文） |
| like（口语里） | 比如/像是 | 删，或换成"就是那种" |
| literally | 字面意义上 | 删（中文里"真的""直接"已够） |
| basically | 基本上 | 换成"说白了""反正" |
| actually | 实际上 | 多数删；要强调时"其实" |
| honestly | 老实说 | "说实话" |
| right? / you see? / you know what I mean | 对吧？/你明白吗？ | 删，或整句变"你看" |
| so（句首） | 所以 | 删，中文直接起句 |
| well | 嗯/那么 | 删 |
| kind of / sort of | 有点儿 | "有点""算是" |
| and stuff / and so on and so forth | 等等之类的 | "之类的"，或干脆删 |
| blah blah blah |  blah blah | "一堆乱七八糟的" |

**保留的例外**：真正推进内容的过渡——Okay so / Now / But first / All right → "好""那么""不过先说"。
这些是信息路标，不是填充，要留，而且要翻成中文的路标说法。

## 2. 情绪与评价：换中国人真会喊的

英文夸人爱用形容词堆，中文夸人用短叹词和程度副词。

| 英文 | 别翻成 | 本地化 |
|---|---|---|
| awesome / amazing / incredible | 令人惊叹的 | 绝了 / 太猛了 / 牛 / 真心强 |
| that's insane / that's crazy | 那太疯狂了 | 离谱 / 疯了 / 这也行 |
| no way | 没门 | 不是吧 / 不至于吧 |
| that's wild | 那很野 | 太离谱了 |
| killer feature | 杀手级功能 | 最狠的一点 / 杀手锏 |
| game changer | 游戏改变者 | 这玩意儿能改玩法 |
| it's a no-brainer | 不需要动脑 | 闭眼入 / 不用想 |
| I love it | 我很喜欢它 | 我太喜欢了 / 这个我服 |
| that's pretty good | 相当不错 | 还不错 / 挺像样 |
| this thing is hella boring | 这东西非常无聊 | 这也太无聊了 |
| I'm really curious | 我真的很好奇 | 我还挺好奇 |
| let's get to work | 让我们开始工作 | 开工 |
| lifesaver | 救命者 | 救星 / 救了大命 |
| bad news / good news | 坏消息/好消息 | 坏消息是 / 好消息是 |
| don't disappoint me | 别让我失望 | 别让我失望（这句可直译，中文也说） |
| it's confusing | 它很令人困惑 | 看得人一头雾水 |
| overwhelmingly | 压倒性地 | （按钮）多到炸 / 看得人发懵 |

程度副词别老用"非常/极其/十分"：换"挺/特别/真/贼/太"，或直接加"了"。
`It works really really great` → `真的特别好用`（不是"它工作得非常非常好"）。

英文里默认观众知道的东西，中文观众可能没概念。保留专名，但补一句"是什么"。

## 9. 句法改造：把英文的骨架拆掉

英文是树状从句，中文是竹状短句。翻完如果一句话里有"的"套"的"、有"被"、有"it"做主语，就是没拆干净。

| 英式结构 | 中文改法 |
|---|---|
| It is + adj + to do | 直接说动词：`做起来挺顺` |
| It was found that... | `发现…` |
| ...which is...（非限定从句） | 拆成另起一句：`…，这个…` |
| 被动式 be + done | 改主动，补出主语；补不出来就用"有人/被" |
| 长定语从句（the X that I did） | 移到前面：`我做的那个 X` |
| and so on and so forth | 删，或"之类的" |
| 多重"的" | 拆成短句 |
| There is / There are | `有…`（或删，直接说主体） |
| I think / I believe（句首） | 多数删，中文直接陈述；真有观点时才留"我觉得" |

**例子**：
- `It has a remote cloud computer that runs 24-7` → `它有一台云电脑，24 小时在线`（拆从句，不是"它有一个全天候运行的远程云电脑"）
- `the onboarding experience is very straightforward` → `上手过程特别顺`（不是"入职体验非常直接明了"）
- `I've been using it as my default harness for the past four or five months` → `这四五个月我都把它当主力工具`（harness 不直译）

## 10. 翻译腔红线（出现即改）

| 翻译腔 | 改成 |
|---|---|
| 让我们… | 咱们… / 直接动词 |
| 这是一个… | 去掉判断，直接说 |
| 在这种情况下 | 这时候 / 这种情况下（可省） |
| 事实上 / 实际上 | 删，或"说白了" |
| 有趣的是 / 值得一提的是 | 删 |
| 我认为这件事非常重要 | 这事挺关键 |
| 进行了一次分析 | 分析了一遍 |
| 做出了贡献 | 帮了忙 |
| 给予了帮助 | 帮了 |
| 被广泛应用于 | 到处都在用 |
| 他/她/它 乱用 | 按语境定，AI 助手用"它" |
| 非常 / 极其 / 十分 堆砌 | 挺 / 特别 / 真 / 太 |
| 然后（连接一切） | 中文靠语序，别每句都"然后" |
| 我们来看看这个 | 你看 / 我们看一眼 |

## 11. 每条字幕的自查 5 问

翻完每一条，问一遍：

1. **中国人会这么开口吗？** —— 念一遍，别扭就重写
2. **有没有更短更常用的说法？** —— 中文口语偏爱短
3. **有没有英文句法的影子？** —— 从句、被动、it is、多重"的"
4. **专名留对了吗？单位换算了吗？** —— 该留英文的别硬翻，该换算的别照抄
5. **一口气念得顺吗？** —— 字幕是听的，不是读的

有一条不过，就重写这条，别凑合。
