# 爆款标题公式库（AI 工具测评方向）

> 来源：TOMOAI 9994 条真实爆款对标标题。每个公式带「结构模板」（可直接套），配真实对标案例。

## 总纲：公式背后都是「标题四驱」（TOMOAI 自研）

每个公式本质都在驱动一种"力"，让读者想点进来：

| 驱动力 | 对应公式 |
|---|---|
| **信息力**（确定性） | 数字量化、保姆教程、干货清单、实测测评 |
| **情绪力**（共鸣/惊喜） | 强悬念、大实话、故事场景 |
| **利益力**（好处） | 免费薅羊毛、痛点+方案 |
| **悬念力**（想知道） | 首发突袭、对比反差、强悬念多变 |

- 短标题靠情绪力+悬疑力冲；长标题要信息力+利益力+情绪力合击。
- 一条标题至少驱动一个力，否则就是"没劲"的废题。

写每个公式时带着"我在驱动哪个力"的意识，标题才有杀伤力。

## 一、数字量化法（最常用 · 库存命中 1759 条）

**一句话**：把"具体成果/具体代价"写成数字，制造确定性与即时感。

**结构模板**：
- `我用【数字】【单位】做了【成果】` → 我用 5 分钟做了个提示词库
- `【N】天/分钟/小时搞定【成果】` → 3 天学会
- `开源【N】天破【N】K【指标】` → 开源 3 天狂揽 7.1K Star
- `【N】个【动作】，【结果】` → 2 个设置就把加载速度提 3 倍

**适用正文**：有明确耗时/数量/收益/星标的任何测评、教程、对比。

**对标案例**：
- 我用 WorkBuddy 5 分钟做了个提示词库，这个功能最让我惊喜
- 开源仅 3 天狂揽 7.1K Star！Browser-Use 把 Jev 模型装进了浏览器 Agent！
- 逼自己练完这 10 个项目，你就是 WorkBuddy 的效率天花板！
- 3 秒出片、0.02 元/秒！OiiOii 上线 Fal H3 Max，又快又省
- 短剧每秒 2 分钱，3 秒出片，6 元搓一集！

**变体**：数字放前面冲击力更强；数字放后面则制造"答案式"克制感。推荐多数放前。

## 二、实测测评法（本号基本盘 · 命中 692 条）

**一句话**：真实体验过，才有话语权。"实测"自带信任光环。

**结构模板**：
- `实测【工具】`：怎么用、效果如何
- `【工具】实机下/{上手/横评}，效果如何` 
- `给 AI 喂【输入】，它会【反应】，横评对比》

**适用于**：任何亲手用过的工具、功能、流程。这是TOMOAI 的招牌。

**对标案例**：
- 实测 | WorkBuddy 新功能：生成微信小程序，打通腾讯生态
- 用 Claude Opus 5.5 做视频堪称一绝，外网已经玩疯了
- 最新服Qoder实测：Qwen3.8- Flash 直接用，我顺手做了个微信文件搜索神器！
- GPT-6：快速上手+横评案例+省Token指南（一篇讲清）
- 给 AI 喂张图，直接出高端 PPT 源文件？WorkBuddy、豆包、GPT-6深度横评

## 三、保姆教程法（粘性拉满 · 命中 1043 条）

**一句话**：把"怎么做到"讲到底，零基础也能跟着做。适合长教程。

**结构模板**：
- `保姆级/手把手/零基础/从0到1 +【教学对象】+ 做成什么`
- `万字拆解：如何用【工具】做【成果】`（配"全文拆解/全套提示词"）
- `0基础速通！手把手教你【动作】完成【成果】`

**适用**：教程贴、实操贴、带步骤的长文。用户要的是"照做能成"的最强确定感。

**对标案例**：
- 零基础入门Opus5.5做视频，万字拆解 AI 是如何用代码做视频的【提示词+Skill全开源】
- 0基础速通！手把手教你用 WorkBuddy 开发出自己的第一个微信小程序
- 腾讯出手！WorkBuddy直接生成小程序：我把《三国》爆改成减肥游戏【附教程】
- 保姆级实操：用 WorkBuddy+IMA 管理知识、构建个人第二大脑

**变体**：加"拆解""全文""全开源"等词强化信息量；加【附提示词】【附教程】给"收藏理由"。

## 四、干货清单法（收藏驱动 · 命中 363 条）

**一句话**：把所有干货整理成清单/合集，读者"先收藏再说"。

**结构模板**：
- `【N】个【类目】清单：全在这了`
- `【主题】合集 / 全集 / 大全：从入门到进阶》
- `【工具】精选【N】条 + 整理`

**适用**：工具清单、Prompt 合集、踩坑避雷、教学大纲。核心是"多"和"全"。

**对标案例**：
- GPT-Image-2 精选 Prompt 合集：59 条实机出图，照抄就能出片
- AI 导演干货｜Blender 入门必学
- 一次性导出微信收藏的文章，AI 自动整理成知识库，效率翻倍！
- 全网首发【】免费从0-1分享所有 AI 视频赛道技巧，424 个技巧全给你

## 五、强悬念法（激发好奇 · 命中 2258 条，概念最宽）

**一句话**：用一个"不应该/没想到/不可思议"的钩子，让读者非得点开看为什么。

**结构模板**：
- `【居然 | 没想到 | 真的假的】+ 反常识事实`
- `用了【】后，我【惊呆/哭了/后悔】`
- `只有【xx人能看懂】+…`

**对标案例**：
- 用 Claude Opus 5.5 做视频堪称一绝，外网已经玩疯了
- 这是目前最好用的 Flash 模型，居然还免费
- OpenAI和Claude都在干的事，没想到Qoder在5月就上线了
- Jev，让全球程序员玩疯了

> 注意：悬念型很吃"信息前置"，必须正文真有一个"出乎意料"的结论，不然就是标题党。

## 六、对比反差法（讨论度拉满 · 命中 352 条）

**一句话**：两个对象硬碰，用"差距/反转"制造站队与讨论。

**结构模板**：
- `【A】vs 【B】，谁更强/更值？`
- `用了【A】，再也不用【B】了`
- `比【B】便宜 80%，还干翻【赛道】`
- `【XX】终于打败/追平【YY】`

**适用**：新工具 vs 老工具、拿一档模型对比评测、实测结果反转。

**对标案例**：
- dots vs Muse vs Grok Bot：AI 智能体大乱斗，谁更能打？
- 谷歌掀桌子！Gemini 4 Argon 刚刚官宣：性能干翻 Astra，价格便宜 80%
- CodeX、ClaudeCode 等顶尖 Agent 全打通，比官方便宜，零门槛使用
- 性比价拉爆！4.59 元，用百度千帆 Token 做了 4 款游戏

> 别乱"吊打"：除非正文实测真赢了，否则是找骂。

## 七、首发突袭法（抢占时效 · 命中 1987 条）

**一句话**：重大发布 = 第一时间告诉读者"来了"。

**结构模板**：
- `刚刚 | 重磅 | 突袭 | 突然发布：【大事】`
- `【公司】官宣：{核心亮点}，数据打脸全场`
- `【模型/工具】上线，被【领域】刷屏`

**适用**：新模型、新功能首发、大会现场、大厂动作。

**对标案例**：
- 谷歌掀桌子！Gemini 4 Argon版刚刚官宣：性能反干 Astra，价格便宜 85%
- 刚刚！Gemini 4 Argon 杀回前三！王牌根基：Token 价只要 1/5
- OpenAI 重磅发布 dots，我在 GitHub 找到一个开源版
- 谷歌 Gemini 4 突袭发布，GPT 和 Opus 都让让

**注意**：首发类要快，时效性是命；别写成"几天前"。角度要新：要么更快，要么更深度。

# 标题动力学：两部表达流派（TOMOAI 自研）

将「标题动力学」落地为两个表达流派，对应「信息力/利益力」与「情绪力/悬念力」两条不同驱动路线。**一篇标题方案应两派都给**（默认 A:B = 5:5）：

## 流派A · 信息驱动型（搜索 SEO 型，关键词密集，信息完整）

**驱动方式**：靠「信息力 + 利益力」——读者一眼看到"能得到什么确定的东西"（数字、步骤、结果），同时关键词可被微信搜到收录。

**适用**：教程、测评、干货、资讯、新功能——用户会主动"来找"的内容。
- 标题**包含关键名词**（模型名/工具名/功能词/人群词），微信搜一搜能命中
- 18-40 字，标题本身可独立成立（不点开也知道讲什么）
- 结构完整：`关键词 + 动作 + 结果/痛点`

**对标案例**（来自TOMOAI 标题库）：
- 实测 | WorkBuddy 新功能：生成微信小程序，打通腾讯生态
- 给 AI 喂张图，直接出高端 PPT 源文件？WorkBuddy、豆包、GPT-6深度横评
- 谷歌Gemini 4突然发布！RSI加持，GPT和Opus都让让
- 0基础速通！手把手教你用 WorkBuddy 开发出自己的第一个微信小程序

**写法要点**：把工具/模型/功能/人群词放进标题前 5 个字；动词紧跟；结果前置。

## 流派B · 情绪驱动型（超短冲突，≤12 字，靠情绪/悬念/冲突出圈）

**驱动方式**：靠「情绪力 + 悬念力」——极短的一句话，在信息流里"一眼扫到"，用反常识或情绪让你停下来。

**适用**：观点、反转、情绪、热点、八卦——靠"抓眼球"传播的内容。

**特征**：
- **极短，一句话**（≤12 字），有冲突感/悬念/情绪
- 读者在信息流里"一眼扫到"，靠反常识或情绪停下来
- 结构示例：观点表达 / 情绪断言 / 悬念提问

⚠️ **整行铁律**：`{工具}恐怖如斯` 这类超短情绪题，**整行就这几个字**，写完整行直接结束，后面绝对不许跟冒号、竖线、补充说明（❌ "Dots 恐怖如斯：它开始主动管你了"；✅ "Dots 恐怖如斯"）。

**对标案例**（来自TOMOAI 标题库，226 条短标题甄选）：
- AI 真的太贵了
- GPT-6 全量发布！
- Codex 太牛逼了....
- RPA 要没了
- 让 AI 上夜班
- 马斯克和奥特曼站到了一起
- 千问办公，上线了｜速测

**经典口诀：`{工具}恐怖如斯` 型**
一句话情绪 + 膜拜/反差，几乎每用每灵（TOMOAI 实战亲测）。类似："XX 太离谱了""XX 杀疯了""XX 封神了"。
- AI 办公 Agent 卷疯了！
- 一步封神！当我的 WorkBuddy 学会了 edulab 技能
- Seedance 2.5 在海外杀疯了！

> 判断侧重：教程干货/信息量大 → 流派 A 为主；观点情绪故事 → 流派 B 为主；两派都出但主次分明。

# 附加：情绪/反差出圈公式（B 流派的底层弹药）

从对话总结 + TOMOAI 标题库提炼形成，主要给超短流做弹药：

**情绪钩子**（贪婪/恐惧/懒惰/惊喜/膜拜/遗憾）：
- "XX 真香""这波亏了""终于等到""被震撼"
- "我只想说一句：XX 真牛"
- "已经是全村的希望"

**前后反差**：
- `从前..，现在..`
- `用前 <-> 用后`（before/after 突显提升）
- `以为不行，结果真香`

**引发好奇**：
- `为什么我劝你 / 别 / 一定要用 XX`
- `XX 到底香不香？我测完告诉你们`
- `万人沉迷的 XX，真面目是什么？`

**经典短句模板**（短标题的盾）：
1. `{工具/模型}太离谱了`（吐槽/膜拜）
2. `{工具}杀疯了`（爆量/超预期）
3. `{工具}直接封神`
4. `真的，{反常识结论}`
5. `终于，{等到的东西}`

# 附加2：踩关键词（流量层级）

**为什么**：99% 的标题要靠关键词带来搜索流量和点击。除了"一个时代结束了"这种可遇不可求的神题，冷门工具的标题都得靠"上位关键词"撑腰。

**流量层级（从最大池到最小池）**：

| 层级 | 关键词 | 例子 |
|---|---|---|
| L1 大厂/平台 | OpenAI、谷歌、腾讯、阿里、字节、Meta、苹果、微软 | 读者人人认得 |
| L2 知名产品 | ChatGPT、Gemini、Claude、Copilot、豆包、WorkBuddy | 圈内懂、圈外听过 |
| L3 小众工具 | Dots、Qoder、Jev | 只有圈内人认识 |
| L4 功能词 | AI 视频、提示词、Agent、数字人 | 泛需求，量大但宽 |

## 使用规则
1. **能往上踩就踩**：写 Dots 时，标题里带"OpenAI 发布 Dots"— 不认识 Dots 的人看到 OpenAI 就知道"这是 OpenAI 的新东西，跟着点看一下"。
2. **冷门工具必须挂母牌子**：WorkBuddy 前面带腾讯；小众模型带 OpenAI/谷歌。没有大厂背书，冷门工具 = 没人点。
3. **一层不够挂两层**：`OpenAI Dots 上线了 24 小时 AI 助手`（大厂 + 工具 + 功能词）。
4. **大厂名 = 信任 + 流量双重**：读者不会因为"一个陌生工具"点开，但会因为"OpenAI/腾讯 出东西了"点开。
5. **例外**：能写出"一个时代结束了"这种普适神题的，不需要踩关键词——那种题可遇不可求，默认还是踩。

**实操**：写每条长标题时自问一句「这个标题里有没有一个 80% 的人都认识的词？没有 → 往上挂一个。」
