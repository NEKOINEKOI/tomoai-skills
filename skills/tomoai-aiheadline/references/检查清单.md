# 中文终审清单（中国人视角标题审查）

> 标题写出来 ≠ 能发。这是**最后一道铁闸**。每一条标题发布前，逐项过这一份清单。
> 它的作用：杀掉 AI 生成的"四不像标题"（AI 腔、歧义、不合时宜），保证每一句都是中国读者一眼就懂、就想点的中文。

## 一、歧义 / 误读检查

**问题**：读者 3 秒扫过，能正确理解你要表达的吗？会不会理解歪？

| 检查 | 说明 | 例子 |
|---|---|---|
| 多义词陷阱 | "恐怖如斯"能懂，"恐怖分子"不行；关键词别被误读 | "XX 心法" → 可能是武功，也可能是方法论 |
| 缩写/英文 | 只有你和圈内人懂的缩写，别在标题用 | "GPT-6 RSI 加持" → RSI 普通人不认识 |
| 歧义结构 | "用 AI 做 PPT" 和 "AI 做的 PPT" 两种读法 | "腾讯悄咪咪上线国内版 Muse" 没问题 |
| 断句歧义 | 换行或标点会让一句话被读成两句 | "5 款工具实测，2 款好用" (哪 2 款？) |

**解法**：把标题对"一个圈外人"复述一遍，若他说"啊？啥意思"，就是有问题，改写。

---

## 二、翻译腔 / AI 腔 检查

** [ ] 这是中国人说的话吗？AI 最常把英文句式和官方词直接搬进中文标题。**

| 不该有 | 该改成 | 说明 |
|---|---|---|
| "作为…" | 直接说 | "作为 AI 博主" → "我测了一年 AI" |
| "值得一提的是" | 删掉或直给 | 公众号标题没有"提示音" |
| "这将极大提升" | "直接起飞" | 别用报告体 |
| "综上所述" | 不说 | 标题里没有"综上" |
| 被动"被…所…" | 主动 | "被 AI 所震撼" → "AI 把我整不会了" |
| "让我们…" | "你 / 我来" | 公众号是对话，不是报告 |
| 美式感叹 | "太顶了" | "Amazing" 换成"绝了" |

**测试**：念出来。像不像朋友在微信里发你的一句话？标题应该像"人话"，不像"官方公告"。

---

## 三、不合时宜 / 敏感 / 越界检查

**这一栏对着中国公众号底线，宁可不说也不惹祸。**

**违禁/敏感（永不出现）**：
- 政治：政治人物、两岸、疆/藏/港等敏感话题（注意"中国香港/澳门/台湾"表述）
- 时政时事争议：重大事件调侃、救灾、疫情笑话
- 涉黄：性暗示、色情描写
- 暴力/血腥：血腥恐怖、自残、凶杀
- 违法：赌博、毒品、诈骗、洗钱
- 医疗/健康承诺："治愈""根治""保证瘦 x 斤"
- 金融/收益承诺："稳赚""躺赚""保本""月入xx万不是梦"
- 绝对化用语（广告法风险）："最""第一""唯一""百分之百""绝无仅有""史上最"
- 虚假/夸大：标题承诺正文没有的东西（点击下去想看的 vs 实际完全不同 → 头条号重罚）

**语言红线**：
- 无低俗："歪""开""舔""死"等涉性、暴力词不碰
- 无迷信、无封建
- 不歧视任何群体（地域、职业、性别、年龄）

**处理**：涉及以上任何一条 → 该标题删除 / 换词 / 重写，不要"我觉得没关系"。

---

## 四、表达 / 情绪正确性

- [ ] 口语化：读起来像人，不像新闻稿
- [ ] 有信息：标题里至少有"一个具体点"，不是"AI 真好用"这种空洞
- [ ] 有钩子：数字 / 对比 / 悬念 / 痛点 / 利益 / 热搜，至少 1 个
- [ ] 有观点/有情绪：是"我觉得 XX 太强了/不稳"这种，不是"XX 发布了"这种公告。**允许标题党、允许夸大，但夸张必须能从正文找到依据**
- [ ] 不油腻不爹味：不用"你还好吗""我教你做人"这类说教味
- [ ] 不喊口号：全是感叹号会疲劳，1 个就够
- [ ] 不悬浮：能把事情说清楚有画面感，不凭空"青春""寂寞"

---

## 五、用前自查（发布前 10 秒）

1. **第一屏**：标题前 3 秒让"刷到的人"停一下吗？
2. **第二屏**：标题和正文强相关吗？（不相关 → 打开率差 + 平台限流）
3. **第三屏**：它站得住吗？换个性别、身份看，还成立吗？
4. **最后**：如果我是 30 岁一线互联网人，为它停下来点什么？点进去会不会失望？

> 你若犹豫"要不要用这条"，说明它还没到"能发"的水平——直接删，再写下一条。标题宁缺毋滥。
