# tomoai-aiheadline — 公众号爆款标题流水线（严格 1-10 步）

> TOMOAI 原创标题体系：基于自研标题库的爆点拆解 + 中文表达语感 + 两流派模型。这是**生产线**不是建议，拿到正文严格按 10 步走，一步不能少，每步输出都要写出来。

---

## 核心原理（自研 · 标题的四个驱动力）

标题让人想点进去，靠的是**驱动读者行动的四个力**，写任何标题都要让至少一个力在起作用：

| 驱动力 | 说明 | 例 |
|---|---|---|
| **信息力** | 告诉读者"能得到什么确定的东西" | 数字、教程、清单、对比、测评 |
| **情绪力** | 触发读者的好奇心/共鸣/惊喜感 | 真香、居然、玩疯了、上头 |
| **利益力** | 直接给好处 | 免费、白嫖、省时间、送额度 |
| **悬念力** | 让读者想知道"然后呢/为什么" | 还藏着这个功能、凭什么这么火 |

- 短标题（≤12字）通常靠 1-2 个力：情绪力+悬念力 冲。
- 长标题（18-40字）必须多力合击：信息力+利益力+情绪力 一起上。
- **标题没有力量 = 白写**：如果四个力都感觉不到，直接重写。
- **没有观点 = 白写**：AI 平铺陈述（"XX 推出新功能"）不是标题，是公告。标题必须带"人"的判断——真香/太强/离谱/废了/该换了，赞或踩都行，就是不能没立场。

> 这是 tomoai-aiheadline 自己的底层判断，不抄任何人的公式，是"这条标题有没有劲"的判据。

## 流水线总览

```
① 通读正文(2遍) → ② 判文章类型 → ③ 提取爆点清单 → ④ 选公式(5-6个) + 踩关键词
⑤ 流A搜索SEO型 → ⑥ 流B超短冲突型 → ⑦ 中文表达校对 → ⑧ 检查清单终审
⑨ 排序+理由 → ⑩ 输出成稿+自评
```

> 每步都有「产出」要求。产出不合格就回去改，不许带病进入下一步。

---

## 第①步 通读正文（2 遍）

**动作**：把用户给的正文完整读 2 遍。
- 第 1 遍：看骨架。讲了什么主题？核心结论是什么？
- 第 2 遍：挖料。数据、案例、功能点、情绪点、金句，全部标出来。**同时问自己：读者看完这篇，能拿走点啥？**（省了时间？省了钱？避了坑？解锁一个以前不知道的可能？）——这就是"读者获得感"，后面标题打的靶子就是它们。

**产出**：2-3 行「内容摘要」，写清"这篇讲的是 X，核心结论是 Y，最有冲击力的点/数据是 Z"。**外加一行：「读者获得感」= 读者看完这篇实际能得到什么。**

---

## 第②步 判文章类型

从下表挑最匹配的 **1-2 类**，写进产出。

| 类型 | 特征 | 主打公式 |
|---|---|---|
| 教程/操作类 | 有步骤、有"怎么做" | 保姆教程、干货清单、命令行动 |
| 实测/测评类 | "我用了/我测了"+结论 | 实测测评、数字量化、强悬念 |
| 对比类 | ≥2 个对象比优劣 | 对比反差、数字量化 |
| 官方报道/资讯 | 新发布、参数、数据 | 首发突袭、权威背书、数字量化 |
| 观点/心得类 | 个人思考、行业观察 | 大实话、强悬念、场景故事 |
| 薅羊毛/福利类 | 免费、送额度、折扣 | 免费类型、痛点+方案 |
| 故事/案例类 | 具体故事/案例 | 故事场景、反转、强悬念 |

**产出**：`本篇属于：XXX 类（主）+ YYY 类（次）`
> 类型判错，后面全部跑偏。这一步是地基。

---

## 第③步 提取爆点清单（标题的弹药库）—— 最关键的一步

把正文里所有可能让读者心动的要素，横着列出来，分类填进下表。**但爆点有真假之分**:

| 爆点类型 | 是什么 | 例子 | 能进标题吗 |
|---|---|---|---|
| ✅ **读者获得感** | 读者看完这篇实际能拿到的东西：省时间/省钱/避坑/解锁新可能/涨见识 | "24小时在线助理""5分钟搭好库""省 80% 时间" | **首选，必用** |
| ⚠️ 认知/判断 | "这是一个时代变了"这种作者的感慨/判断 | "不用管 AI 了，AI 来管你" | 只配当情感调料，**不能当主钩子** |
| ⚠️ 行业观察 | 有点懂行但读者不 care 的信息 | "dots 改变了 agent 形态" | 圈内自嗨，别当主钩 |
| ❌ 作者自爽 | 只有你自己觉得牛的东西 | 我用了什么工具、我悟了什么 | 删掉，读者没感觉 |

> **爆点判定的硬规则**：标题的钩子必须给"读者的获得感"，不能给"作者的感动"。如果提炼出来的点，读者第一反应是"关我屁事"，那它就不是爆点——哪怕它是整篇文章最高的认知。

从正文里挖的时候，用「获得感」当筛子，分类填：

| 类别 | 从正文挖什么 | 示例 |
|---|---|---|
| 核心结论 | 这篇最重要的 1-2 个点 | "零代码 5 分钟搭提示词库" |
| 硬数据 | 耗时/数量/价格/倍率/星标 | 5 分钟 / 60 条 / 秒出 |
| 省钱省时 | 帮读者省了啥 | 省 60% 额度 / 省一下午 |
| 避坑 | 读者不再踩的雷 | "终于有人把坑讲干净了" |
| 对比反差 | 用前vs用后、慢vs快 | 从翻半天 → 秒检索 |
| 痛点共鸣 | 读者自己天天在痛的事 | 提示词散落找不到 |
| 情绪点 | 惊喜/意外/真香/反转 | "居然…还挺香" |
| 关键名词 | 工具/模型/大厂/人群 | WorkBuddy、公众号、写作者 |

对每一个爆点，写一条短句（3-5 字），放进清单。

**产出**：至少 6-10 个爆点条目，其中 **必须有一半以上属于「获得感」类**。标注每条是"获得感/认知/行业观察/自爽"哪一档。
> 后面的标题只能从这些爆点取材。**没有进入这个清单的信息，不允许进标题。**
> **第③步不过关 = 后面全是废标题**：如果发现爆点全是"认知/判断/作者感受"，停在这里，回头读正文重新挖。挖到真正让读者心动的点再往下走。

---

## 第④步 选公式（5-6 个）

打开 `references/formulas.md`，按 **文章类型 → 可用公式** 选 5-6 个。

**选择规则**：
- 教程/实测 → 必选【保姆】【实测】【数字】
- 有硬数据 → 必选【数字量化】【对比】
- 有免费/低价 → 必选【免费薅羊毛】【痛点+方案】
- 有发布/新品 → 必选【首发突袭】【权威背书】
- 观点文 → 带【观点】【强悬念】
- 有故事 → 带【故事场景】【反转】
- **别贪多**：5-6 个就够，把这 5-6 个写透优于 12 个凑数。

**⚠️ 踩关键词（流量层级）**：
标题要带能被搜到、能被点开的关键词。但关键词有**流量层级**，优先级从高到低：
1. **大厂/平台名**（最大流量池）：OpenAI、谷歌、腾讯、阿里、字节、Meta…
2. **知名产品名**：ChatGPT、Gemini、Claude、WorkBuddy…
3. 小众产品名：Dots、Qoder、Jev…
4. 功能词：Agent、AI 视频、提示词…

**规则**：
- **受众越小众，越要往上踩**：Dots 没人懂 → 标题必须带 OpenAI 或 ChatGPT；WorkBuddy 知道的人有限 → 带"腾讯"或"腾讯生态"拉流量。
- 小众工具名前，**能挂母公司就挂**：`OpenAI 发布 Dots` 比 `Dots 发布` 强 10 倍，前者让不懂的人也知道是"OpenAI 出的新东西，值得看"。
- **大厂名 = 信任背书**：读者对陌生工具的点击率，全靠"哦这是 OpenAI/腾讯出的"撑着。没有这层背书，冷门工具标题就是裸奔。

> 一句话：**给读者一个"我知道这是什么来头"的锚点。** 冷门工具 + 不挂大厂 = 没人点。
> 例外：如果你能写出"一个时代结束了"这种神级短标题，可以不用踩关键词——但那种标题可遇不可求，默认都要踩。

**产出**：列 5-6 个选中的公式名 + 本条标题要踩的**关键词层级**（大厂 / 产品 / 人群），并说明为什么。

## 第⑤步 流派 A · 搜索 SEO 型

打开 references/formulas.md 的「两大流派」章节，理解 A 型规则后，写 **5-6 条**：

- 字数 18-40，关键词密（工具/模型/功能词放前 6 字）
- 动词紧跟，结果前置
- 适合教程/测评/干货
- **必须踩关键词层级**（见第④步）：工具不够出名 → 前 6 字挂大厂/母公司名。
  - ❌ "Dots 发布，24 小时 AI 助手"（Dots 谁懂？没人点）
  - ✅ "OpenAI 发布 Dots：24 小时在线的 AI 助手"（OpenAI 背书，路人也想点）
- **钩子必须给"获得感"**：这句标题给读者的好处要一眼可见（省时/省钱/避坑/涨见识），不是"我测了个新东西"。

参考爆款：
- 实测 | WorkBuddy 新功能：生成微信小程序，打通腾讯生态
- 给 AI 喂张图，直接出高端 PPT 源文件？WorkBuddy、豆包、GPT-6深度横评
- 0基础速通！手把手教你用 WorkBuddy 开发小程序

---

## 第⑥步 流派 B · 情绪驱动型：超短冲突标题（≤12 字）

覆盖 **5-6 条**超短标题。

> **宁缺毋滥**：10 条全像 AI 写的，不如 5 条真想明白的。如果某条改 3 遍还觉得"就是差点劲儿"，删掉它，把省下的力气花在打磨剩下的高质量标题上。数量是及格线，质量是生死线。

**铁律（死规定，违反即重写）**：
- **整行 = 这几个字**。写完整行就结束，**后面绝对不允许再跟冒号、竖线、逗号续句、补充说明**。
  - ❌ "Dots 恐怖如斯：它开始主动管你了"（违规：后面跟了内容）
  - ✅ "Dots 恐怖如斯"（整行五个字，斩钉截铁，直接就是这一句，结束）
- 一条 = 一口气读完。多用句号/感叹号结尾。
- 像人在聊天群里拍桌子发的一句话，不是新闻标题。
- **内容必须有态度**：赞就"封神/恐怖如斯/太顶了"，踩就"废了/白折腾/又一个噱头"，不许"客观介绍"。

**经典写法（对照参考，整行不带后缀）**：
- `{工具}恐怖如斯`（斩钉截铁)
- `{工具}杀疯了` / `{工具}封神了` / `{工具}太离谱了`
- `AI 真的太贵了` / `RPA 要没了` / `Codex 太牛逼了`
- `XX 终于...了`

**动笔前动作（强制）**：先打开 `references/examples.md` + `references/formulas.md` 的流派B部分，**默读 5 条原始案例**，用它们的语气、节奏、斩截感写，不要自己发明腔调。

---

## 第⑦步 中文表达校对（对标参考 `references/中文表达.md`）

**动笔前强制动作（第⑤⑥步执行前做，不许跳过）**：
1. 打开 `references/examples.md`，定位文章类型对应的公式章节；
2. **默读 5 条该类型的原始爆款**（至少出声读，感受节奏、语气）；
3. 同时打开 `references/中文表达.md`，挑 2 个要用的口语词/句式，锚定；
4. 才开始动笔。**没读就写，等于白写**——AI 没有语感，不抄就露馅。

**必须像"先抄后写"**：标题要能在这些原始例子里找到"同一句话的影子"，而不是自己发明一套 AI 腔。

每一条刚写的标题，用「中文表达特征库」逐条自检：

- [ ] 是一条中国人会说的话吗？（不是"官方公告"也不是"AI 翻译"）
- [ ] 是否用了中文高频口语词（真的/太/绝了/居然/白嫖/上头…）？没有 → 补一个
- [ ] 是否有中文口语句式（还得是/完蛋了/这你受得了/凭什么是…）？可以带一句
- [ ] 有没有英文腔/报告腔（作为/值得一提/显著提升/综上所述）？有 → 重写
- [ ] 读出来像"跟朋友聊天"还是"官方公告"？像公告 → 重写
- [ ] 把标题里的主体名换掉再念一遍：**和你刚读的那条案例撞了 60% 以上？** → 是套模板，重写

**产出**：标出每条标题用到的表达/句式（如"用了'居然'+数字"）。这给排序做依据。

---

## 第⑧步 检查清单终审

每一条标题依次过 `references/检查清单.md` 五段：
1. 歧义/误读（圈外人3秒理解对吗）
2. 翻译腔/AI 腔（改）
3. 违规/违禁/敏感/绝对化/虚假（删或改）
4. 表达/情绪（口语、有信息、有钩子、不爹味）
5. 用前自查（3 秒停不停？与正文相关？）

**额外铁闸（自媒体锋利度）**：
- **宁可尖锐，不要平庸**：标题党/夸大/个人判断是这行的生存技能，不是错误。一条标题如果引不起任何情绪（既没人骂也没人点），就是失败。
- **夸张要有出处**：可以"封神""恐怖如斯""太离谱了"，但夸张的砝码必须来自正文（性能、价格、难度、效果），不能空口吹数。
- **不碰红线**：虚假数据、绝对化承诺、医疗/金融收益承诺、违法词，统统不行。
- **不合格处理**：太四平八稳 → 添一笔情绪/悬念；过了火 → 拉回一点。删掉没有力量、没有立场、圈外人看不懂的。

**不过直接删/重写**。终审后留下来的就是合格题。

---

## 第⑨步 排序 + 理由

把合格的标题按**预估点击效果**排序：

- 排序依据：**钩子打中"读者获得感"的强度**（省时/省钱/避坑/涨见识）→ 目标读者命中程度 → 关键词携带量（大厂>产品>功能）→ 与正文契合度
- 第 1 名 = 你推荐用户直接用的那条。
- **如果排序时发现所有标题的钩子都是"作者认知/行业观察"而没有一个"读者获得感" → 回去重做第③步，别带着废弹上榜。**

对每条标题写一句**理由**：用了哪个公式/哪个流派 + 钩子打中的"获得感" + 踩了什么关键词 + 对标库哪个爆款。
例：
```
【第1名】OpenAI 发布 Dots：24 小时在线的 AI 助手
  → 钩子=获得感（一个 24 小时干活的新助手）+ 踩了 OpenAI 大厂词 + 对标「刚刚，谷歌 Gemini 杀回前三」同款。
【第2名】...
```

```
## 《<文章标题/主题>》爆款标题方案（共 N 条）

【第1名·强烈推荐】<标题>
   → 解析
【第2名】<标题>
   → 解析
…
【第N名】<标题>
   → 解析

## 备选池（未进前列，可择用）
- <标题>（why what）
- …

## 自评说明
```

## 铁律（不适合用户的内容）
- 忠于正文：标题信息必须能在正文找到，不虚构数据
- **标题党是技能不是错误**：可以夸大情绪、可以藏一手，但点击后正文要接得住，不能"挂羊头卖狗肉"
- 合规：不碰违禁词、敏感话题、绝对化/虚假承诺、医疗/金融收益承诺
- 中文第一：所有标题必须像中国人写的，宁口语不书面
